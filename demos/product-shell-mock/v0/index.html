Why this mock type exists
Native code is expensive to thrash. Clickable dual-surface HTML is cheap. Use it when the question is “where does this control live?” not “is the type ramp perfect?”.

Chooser rules (ship from mock)
1. Pills = product context registry (here: greenmark · aic · eidos · reeves · unsorted).
2. Selected pill filters every “In context” surface; badge = pending for that context.
3. Inbox under You = all-contexts rollup; cards keep a context chip.
4. Persist last pill; Unsorted is first-class.
5. See ../TECHNIQUE.md for the agent recipe.
