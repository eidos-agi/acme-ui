Acme UI

Reference frontends for humans watching agents work.

Live demos of the interaction grain that makes agent chat feel great — realtime, legible, calm. Each demo is a scripted agent turn you can watch and interrupt: informed, never overwhelmed. Brand-neutral by design; every color and size is a token you can swap.
