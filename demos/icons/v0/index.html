Every sample above is the package's real SVG, inlined from its published release (all MIT licensed). Same five ideas, five different voices — pick one voice and stay in it.

Rules

  • Pick one set per product. Mixing sets reads as sloppily as emojis do.
  • Inherit currentColor; never hardcode icon fills.
  • One stroke width everywhere (this page uses a --icon-stroke token).
  • Size in rem next to text (here 1.05rem in rows, 1.3rem in the grid).
  • Emojis stay in user content, where users typed them. Chrome is not user content.
  • In React: import { House, Send, Square } from "lucide-react". Static HTML: inline the SVG, like this page.

Every icon on this page is inline Lucide SVG (ISC license). No icon font, no CDN, no emoji.
