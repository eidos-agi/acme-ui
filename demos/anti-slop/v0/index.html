eidos ui anti-slop v0

AI that doesn't sound like AI.

LLMs share a house style, and readers have learned to smell it: the same fifty words, everything in threes, punchy fragments, a bright little summary at the end. Anti-slop is a set of hard rules that block those patterns at generation time. Same model, different instructions, prose a human would sign.

How it works

LayerWhat it does
Banned lexiconA merged blocklist (community lists + house additions) of words and phrases that fingerprint AI prose: delve, leverage, seamless, robust, game-changer, it's worth noting, in today's fast-paced… The list regenerates from upstream sources with provenance tags.
Structural rulesNo rule of three by default. No "it's not X, it's Y" unless the contrast is load-bearing. Vary sentence length. One em dash per ~500 words. Active voice. End on a concrete detail, never a bright summary.
Specifics testNumbers, names, mechanisms instead of adjectives. The tell for slop is prose any AI could write for any person — the fix is a detail only this author could know.
Silent self-checkBefore output: banned words? three same-length sentences in a row? artificial threes? em-dash pile? generic opener? motivational closer? Applied without announcing it.
Audit passA separate reviewer (anti-slop-audit) runs post-draft and returns a punch list: file, line, category, offending phrase, suggested rewrite.

Install it

Anti-slop ships as a plugin from the Eidos marketplace (source: eidos-agi/anti-slop), with three skills: anti-slop (constrains generation), anti-slop-audit (reviews drafts), and world-class-case-study (long-form structure).

# Claude Code
claude plugins install anti-slop@eidos-marketplace

# Grok
grok plugin marketplace add eidos-agi/eidos-marketplace
grok plugin install anti-slop --trust && grok plugin enable anti-slop

Rules that carry this site

  • Every headline and rung description on eidos-ui passed through these rules. The one that slipped ("grown in public") got caught by the founder in minutes, which is the point: readers notice.
  • Slop is not a writing-quality issue; it is a trust issue. Prose that smells generated makes readers discount the claims inside it.
  • The rewrite is always more specific than the original. If you cannot add a number, a name, or a mechanism, you do not know enough to write the sentence yet.
