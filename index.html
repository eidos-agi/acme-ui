Chat interfaces like the major companies.

Demos for agent products, rebuilt version by version. Each version fixes one named problem and stays online. Click anything in the sidebar: the demo plays itself, the source shows on the right, and one button copies agent-ready instructions for using the pattern in your own app.

Chat versions are checked against the acceptance list in brief 01 of eidos-agi/ui-patterns. Every chat demo talks to the same mock agent (chat-events v1.1); the agent code never changes between versions. Shell mocks use only in-page JS. Acme is a placeholder brand; colors and sizes are CSS tokens you can swap.
